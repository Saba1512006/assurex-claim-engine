Train and install the Teachable Machine model

  1. Download the training cards — {{ dataset.get('splits', {}).get('train', {}).get('rows', 1050) * 2 }} images in three class folders (two variations per training claim). Validation and test cards are not included.
    Download training cards (.zip)
  2. Open teachablemachine.withgoogle.com → Image Project → Standard image model.
  3. Rename the classes to Valid Claim, Invalid Claim and Manual Review and upload each folder into its class.
  4. Train (defaults: 50 epochs, batch 16, learning rate 0.001 are a good start).
  5. Export Model → Tensorflow Lite → Floating point → Download. Unzip it.
  6. Upload model_unquant.tflite and labels.txt here, then run the evaluation.
